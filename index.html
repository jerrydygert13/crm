SECURITY

BACKUP & RESTORE

Data lives in this browser. Export a backup file regularly (recommended: once a week after a busy weekend).

HOW THIS CRM WORKS

• With Cloud Sync connected: website requests appear in Leads automatically — nothing to copy.
• You also get the Formspree email for every request (your phone-side heads-up).
• Move leads through: New → Contacted → Scheduled → Won (or Lost).
• Scheduling a job puts it on the Calendar; marking it Completed counts toward revenue.
• Leads that sit too long show up under Needs Attention on the Dashboard.
• Add phone/text callers manually with + Add Lead — takes 10 seconds.

Without Cloud Sync, everything still works — it's just saved in this browser only, and website leads arrive by email only.
